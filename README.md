# ОПИСАНИЕ ПРОГРАММЫ

Документ составлен в соответствии с требованиями ГОСТ 19.402-78 «Единая
система программной документации. Описание программы».

## 1. Общие сведения

**Наименование программы:** Dashboard — информационная панель мониторинга
системы накопления энергии.

**Обозначение системы:** программа реализована на языке программирования
Python (версия 3.10 и выше) с использованием веб-фреймворка NiceGUI.

**Программное обеспечение, необходимое для функционирования программы:**

| Компонент | Требование |
|---|---|
| Python | 3.10 или выше |
| nicegui | согласно `requirements.txt` |
| PyYAML | согласно `requirements.txt` |
| Веб-браузер | с поддержкой HTML5, CSS3, JavaScript |

Полный перечень зависимостей приведён в файле `requirements.txt`.

## 2. Функциональное назначение

Программа предназначена для визуального отображения в реальном времени
параметров системы накопления энергии (аккумуляторной батареи и связанного
с ней оборудования), поступающих по интерфейсу CAN.

Программа решает следующие задачи:

- отображение состояния подсистем электрохимического
  преобразователя (ЕС): предупреждения, ошибки, число полных циклов заряда;
- отображение состояния силового преобразователя (напряжения и токи входа
  и выхода, режим работы, состояние контактора);
- отображение сводной таблицы состояний подсистем (преобразователь,
  конденсаторная батарея, контроль изоляции, система охлаждения) с
  индикацией числа ошибок и времени отклика линии связи;
- отображение уровня заряда (SoC) и степени износа (SoH) аккумуляторной
  батареи, а также запасённой энергии;
- отображение напряжения, тока и температуры;
- отображение состояния силовых контакторов;
- отображение параметров системы охлаждения (обороты вентиляторов,
  положение заслонок);
- приём команд оператора через интерфейс командной строки;
- переключение между тёмной и светлой цветовыми темами интерфейса.

Программа не выполняет приём и разбор кадров CAN-шины самостоятельно.
Значения параметров, отображаемых на панели, поступают от внешней
программы-источника данных и передаются в программу через словарь
параметров (см. раздел 6). В отсутствие внешнего источника данных все
параметры принимают нулевые либо нейтральные значения.

## 3. Описание логической структуры

Программа построена по модульному принципу. Состав модулей каталога `app/`
приведён в таблице.

| Модуль | Назначение |
|---|---|
| `run.py` | точка входа; запускает программу |
| `app.py` | сборка страницы панели, функция `main()` |
| `config.py` | пороговые значения и константы (SoC, SoH, напряжение, ток, температура) |
| `parameters.py` | словарь текущих значений параметров `PARAMETERS` и перечень подсистем `SYSTEMS` |
| `colors.py` | функции определения цвета индикации по состоянию либо значению параметра |
| `helpers.py` | вспомогательные функции расчёта (сегменты индикатора, форматирование времени отклика) |
| `styles.py` | глобальные стили интерфейса, CSS-переменные тёмной и светлой темы |
| `layout.py` | загрузка файла раскладки `pattern.yaml`, построение CSS-сетки |
| `cells.py` | функции отображения содержимого ячеек панели |
| `command_line.py` | виджет командной строки оператора |

Расположение и состав ячеек панели задаются декларативно в файле
`pattern.yaml`, расположенном в корневом каталоге репозитория. Файл
определяет число строк и столбцов сетки, области размещения ячеек и
заголовок каждой ячейки. Сопоставление заголовка ячейки с функцией
отображения выполняется в модуле `cells.py`.

Программа использует однократную загрузку файла раскладки при старте и
построение содержимого страницы для каждого подключившегося клиента
средствами NiceGUI (`@ui.page`).

## 4. Используемые технические средства

Для функционирования программы требуется персональная электронно-
вычислительная машина, обеспечивающая работу интерпретатора Python 3.10
и выше. Операционная система — без ограничений (Windows, Linux, macOS).
Для просмотра панели требуется рабочая станция с установленным
веб-браузером, имеющая сетевой доступ к узлу, на котором запущена
программа.

## 5. Вызов и загрузка

Установка зависимостей выполняется командой:

```
pip install -r requirements.txt
```

Запуск программы выполняется командой:

```
python app/run.py
```

После запуска программа поднимает веб-сервер и выводит в консоль адрес
для подключения (по умолчанию `http://localhost:8080`). Панель
открывается в браузере по указанному адресу.

## 6. Входные данные

Входными данными программы являются:

1. **Файл раскладки `pattern.yaml`** — определяет структуру сетки панели:
   количество столбцов и строк, карту областей и заголовки ячеек.
2. **Словарь параметров `PARAMETERS`** (модуль `app/parameters.py`) —
   содержит значения телеметрии, отображаемые на панели (состояния
   подсистем, уровни SoC/SoH, напряжение, ток, температура, обороты
   вентиляторов и иные показатели). В поставляемой версии программы
   значения инициализированы нулём либо нейтральным состоянием `"NONE"` и
   подлежат заполнению внешней программой, осуществляющей приём и разбор
   данных CAN-шины.
3. **Команды оператора**, вводимые через интерфейс командной строки
   панели.

## 7. Выходные данные

Выходными данными программы является веб-страница, формируемая
средствами NiceGUI и отображаемая в браузере оператора. Страница содержит
графическое представление текущих значений параметров системы,
цветовую индикацию состояний и предупреждений, а также элемент
переключения цветовой темы интерфейса.
