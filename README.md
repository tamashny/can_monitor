# Dashboard

Веб-панель мониторинга системы накопления энергии (аккумуляторная батарея
и связанное оборудование) с данными по интерфейсу CAN. Сделана на
[NiceGUI](https://nicegui.io/).

## Что показывает панель

- статус электрохимического преобразователя (ЕС): предупреждения, ошибки, число полных циклов заряда;
- статус силового преобразователя: напряжения и токи входа/выхода, режим работы, состояние контактора;
- сводную таблицу состояний подсистем (преобразователь, конденсаторная батарея, контроль изоляции, охлаждение) с числом ошибок и временем отклика линии связи;
- заряд (SoC) и износ (SoH) батареи, запасённую энергию;
- напряжение, ток и температуру;
- состояние силовых контакторов;
- параметры охлаждения (обороты вентиляторов, положение заслонок);
- командную строку оператора;
- переключение тёмной/светлой темы.

Сама панель не читает и не разбирает CAN-шину — значения параметров ей
подаёт извне другая программа (реальный источник или симулятор), через
словарь `PARAMETERS`. Пока такого источника нет, все значения нулевые
или нейтральные (`"NONE"`).

## Структура проекта

```
app/
  app.py            — точка входа: запускает NiceGUI и собирает страницу
  protocol.py       — разбор кадров CAN-шины по описанию из canmap.yaml
  frontend/
    layout.py       — загрузка pattern.yaml, построение CSS-сетки
    cells.py        — отображение содержимого ячеек панели
    command_line.py — виджет командной строки
    colors.py       — цвета индикации по состоянию/значению
    parameters.py   — словарь текущих значений PARAMETERS
    config.py       — пороги и константы (SoC, SoH, напряжение, ток, температура)
    styles.py        — глобальные стили и CSS-темы
pattern.yaml         — раскладка панели: сетка, области, заголовки ячеек
canmap.yaml           — карта CAN-кадров (какие байты что значат)
can_map.xlsx          — та же карта в виде таблицы
vcan/                 — симулятор CAN-шины для тестов без реального оборудования
requirements.txt
```

Раскладка ячеек (сколько строк/столбцов, где что стоит, заголовки)
задаётся декларативно в `pattern.yaml`. За то, какой виджет рисуется под
каким заголовком, отвечает `app/frontend/cells.py`.

## Запуск

```
pip install -r requirements.txt
python app/app.py
```

Дальше NiceGUI поднимет веб-сервер и покажет адрес в консоли (по
умолчанию `http://localhost:8080`) — открывайте его в браузере.

Для теста без настоящей CAN-шины можно поднять виртуальный интерфейс и
погонять по нему случайные кадры через `vcan/vcan.py` (линукс-only,
использует `vcan`/`socketcan`).

## Требования

- Python 3.10+
- зависимости из `requirements.txt` (NiceGUI, PyYAML, python-can)
- браузер с поддержкой HTML5/CSS3/JS
